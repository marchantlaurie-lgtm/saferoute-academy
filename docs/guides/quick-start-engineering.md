# Engineering Quick Start

[Open this Quick Start inside the beta](https://saferoute-academy-git-academy-engineering-cfi-4aa47c-saferoute1.vercel.app/?guide=engineering)

1. Choose **Flight School / Club → Engineering Login**.
2. Scan Serviceable, Restricted, Unavailable and Open Defects.
3. Select a fictional aircraft and review state/maintenance information.
4. Change it to **Restricted** and add a clearly fictional defect.
5. Review the generated defect and audit entry.
6. Log out and confirm Pilot / Ops shows the restriction/defect.
7. Return to Engineering and change the aircraft to **Maintenance** or **Unserviceable**.
8. Confirm Pilot / Ops now blocks selection.
9. Test Close Defect, Record 100-Hour Complete or Return to Service as appropriate.
10. Remember that Return to Service is a fictional workflow action, not a regulatory maintenance release.

Evaluate whether state, restriction and defect context are unambiguous and whether prohibitions block the workflow rather than merely adding risk points.
