# Pilot / Ops Quick Start

[Open this Quick Start inside the beta](https://saferoute-academy-git-academy-engineering-cfi-4aa47c-saferoute1.vercel.app/?guide=pilot-ops)

1. Choose **Flight School / Club → Pilot / Ops Login**.
2. Use only the fictional records supplied.
3. Select a pilot, then an aircraft.
4. Green is serviceable; yellow carries restrictions/defects; red maintenance/grounded aircraft and unauthorised types are blocked.
5. Read every CFI Action Required, advisory or blocked message.
6. Choose **Start Pre-Flight Risk Assessment**.
7. Check which answers are **Academy Auto-Fill** and which require **Pilot Input**.
8. Complete Pilot, Aircraft, Environment and External Pressures. Sleep, IMSAFE, weather/personal minima, performance, fuel and external pressure remain manual.
9. Review Initial Risk, record genuine controls for material factors, then complete the Residual Risk comparison.
10. Treat the result as decision support only. It does not authorise flight, establish currency or determine airworthiness.

Evaluate whether blocks/advisories are clear, sources are visible, and the three-stage FRAT supports rather than replaces PIC/CFI judgement.
