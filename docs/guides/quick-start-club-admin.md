# Club Admin Quick Start

[Open this Quick Start inside the beta](https://saferoute-academy-git-academy-engineering-cfi-4aa47c-saferoute1.vercel.app/?guide=club-admin)

1. Choose **Flight School / Club → Club Admin**.
2. Scan user, pilot, aircraft and defect summary cards.
3. Select a fictional user in **Users & Access**.
4. Review status, workspace roles and linked pilot information.
5. Add/remove a demo workspace role.
6. Test Active/Suspended status. The final active Club Admin is protected.
7. Review Organisation/Test Settings and the locked safety-policy list.
8. Review Recent Prototype Activity, then log out/re-enter to confirm persistence.

Evaluate whether access control is clearly separate from CFI/Engineering authority and whether safeguards/activity provide useful oversight.
