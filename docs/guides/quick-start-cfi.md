# CFI / Training Quick Start

[Open this Quick Start inside the beta](https://saferoute-academy-git-academy-engineering-cfi-4aa47c-saferoute1.vercel.app/?guide=cfi)

1. Choose **Flight School / Club → Independent CFI / Training Trial**.
2. Scan Current, Due Soon, Action Required and Awaiting Sign-off.
3. Select a yellow or red pilot and identify the highlighted reason.
4. Review recency, currency, check and medical summary fields.
5. Toggle a fictional aircraft-type authorisation.
6. Use **Mark Due Soon** or **Require Training** to test attention states.
7. Use **Record Check / Sign Off** to return the fictional record to Current.
8. Log out and enter Pilot / Ops to verify the shared effect.
9. Start a FRAT and confirm record-backed context appears while human-only factors remain manual.

These are fictional workflow actions, not regulatory endorsements or official training records. Evaluate whether the CFI can immediately see who needs action, why and what changes downstream.
